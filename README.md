# Apple Stock Market Analysis

A Python-based exploratory analysis of **Apple (AAPL)** stock market data from **2018–2022**, using data retrieved through Yahoo Finance.

## Overview

This project examines historical AAPL market data to identify trends in stock prices, trading volume, and daily returns. It also compares Apple's performance with the **S&P 500**.

## Analysis

- Historical high and low prices
- Yearly average closing prices
- Monthly average trading volume
- Daily return analysis
- 50-day and 200-day moving averages
- Comparison of AAPL and S&P 500 closing prices
- Correlation between AAPL and S&P 500 daily returns
- Return distributions and correlation visualization

## Technologies

- Python
- Pandas
- Matplotlib
- yfinance
- Jupyter Notebook

## Data

Stock data is retrieved from **Yahoo Finance** using the `yfinance` library. The analysis covers AAPL and the S&P 500 from **January 2018 through December 2022**.

Install the required packages:
